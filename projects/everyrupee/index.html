EveryRupee

Active

A WhatsApp-based tool for recording and reviewing personal expenses.

The problem

Most people don’t keep an expense record because opening a separate app and filling in a form is too much effort for a Rs.400 bus fare. Chat is already open all day. EveryRupee brings expense tracking to the place people already are.

What it does

  • Records an expense from a plain message such as “Add 400 to bus”.
  • Confirms what it recorded, so mistakes are visible straight away.
  • Produces a monthly summary with the total and a breakdown by category.
  • Lets the user undo the last entry.

Architecture

A message reaches the backend through the WhatsApp Business API. The backend interprets the text, stores the transaction, and sends back a confirmation or summary.

Implementation

The core work is in the backend: receiving messages reliably, turning free text into an amount and a category, storing transactions, and aggregating them for summaries. Keeping the commands short keeps the parsing predictable.
